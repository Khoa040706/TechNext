# Prompt 01 – Read Project First

Hãy đọc kỹ toàn bộ dự án NextTech trước khi thực hiện bất kỳ thay đổi nào.

Thứ tự bắt buộc:
1. Đọc toàn bộ cấu trúc thư mục và source code hiện có.
2. Đọc `context.md`.
3. Đọc `AGENTS.md`.
4. Đọc `docs/technical/tech-stack.md`.
5. Đọc `plan/README.md` và `plan/00-overview.md`.
6. Đọc các tài liệu trong `docs/` để hiểu requirements, domain, UI/UX, API, AI/Data.
7. Đọc toàn bộ thư mục `plan/` để hiểu thứ tự triển khai FE → BE → AI/Data → Integration → Testing → Release.

YÊU CẦU QUAN TRỌNG:
- CHƯA sửa code.
- CHƯA tạo file mới.
- CHƯA implement bất kỳ task nào.
- KHÔNG tạo implementation plan, implementation-plan.md, TODO plan hoặc kế hoạch riêng.
- Không thay đổi các tài liệu hiện tại.
- KHÔNG tự thay tech stack. `docs/technical/tech-stack.md` là stack chính thức.

Sau khi đọc xong, chỉ báo cáo ngắn gọn:
- Kiến trúc/source code hiện tại.
- Tech stack hiện tại có khớp `tech-stack.md` không.
- Những phần đã có.
- Những phần còn thiếu so với `plan/`.
- Plan đầu tiên cần thực hiện.
- Các vấn đề/mâu thuẫn nếu phát hiện.

Không bắt đầu implementation cho đến khi tôi gửi prompt tiếp theo.
