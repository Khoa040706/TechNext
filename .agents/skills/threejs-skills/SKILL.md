# Three.js Skills

Skill focus:
- `threejs-fundamentals`: Scene, PerspectiveCamera, WebGLRenderer, animation loop, resize handling.
- `threejs-geometry`: BufferGeometry, custom parametric shapes, instanced rendering (`InstancedMesh`).
- `threejs-materials`: MeshPhysicalMaterial, PBR glass refraction, custom ShaderMaterial with GLSL uniforms.
- `threejs-lighting`: DirectionalLight, PointLight, RectAreaLight, shadows, Environment Maps.
- `threejs-postprocessing`: EffectComposer, UnrealBloomPass, DepthOfField, custom shader passes.
- `threejs-interaction`: Raycasting, OrbitControls, mouse/touch 3D object selection.
