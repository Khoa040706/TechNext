# Taste Skill (Anti-Slop Frontend)

Skill focus:
- Brief inference & read the room before code generation.
- Three design dials: DESIGN_VARIANCE, MOTION_INTENSITY, VISUAL_DENSITY.
- Color restraint & Lila rule: Max 1 accent color, ban AI-purple slop gradients, enforce monochrome/emerald/cobalt luxury palettes.
- Typography discipline: Sans-display priority, ban random display serifs as default, strict italic descender clearance.
- Hard layout rules: Viewport-bound hero, max 20 words subtext, max 1 eyebrow per 3 sections, single-line navbar cap.
