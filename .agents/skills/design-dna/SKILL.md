# Design DNA

A 3-phase workflow for extracting, structuring, and applying design identity:
1. **Design System** — measurable tokens (color, typography, spacing, layout, shape, elevation, motion)
2. **Design Style** — qualitative perception (mood, visual language, composition, interaction feel)
3. **Visual Effects** — special rendering (Canvas, WebGL, 3D, particles, shaders, scroll effects, glassmorphism)
